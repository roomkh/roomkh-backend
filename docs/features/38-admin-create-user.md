# Feature: Admin Create User API

- **Status:** Completed
- **Branch:** `feature/admin-create-user`
- **Related Commit:** `feat: add admin api to manually create users and owners`

## Purpose
Enables platform administrators to manually onboard standard users or property owners (sellers) directly from the Admin Dashboard. This bypasses the public registration flow and the manual approval queue, granting instant access to the platform.

## Logic & Flow
- **Email Validation:** Prevents duplicate accounts by checking the database for the provided email before proceeding.
- **Role Resolution:** Maps the requested role string directly to the `RoleName` enum and fetches the corresponding entity.
- **Security:** Encodes the raw password payload securely via `PasswordEncoder` before saving it to the database.
- **Auto-Activation:** Accounts are instantly assigned `AccountStatus.ACTIVE`.
- **Auto-Approval:** If the account role is assigned as `SELLER`, the `SellerStatus` is automatically flipped to `APPROVED`. For standard `USER`s, this field is left null.

## Endpoint & Security
- **Path:** `POST /api/v1/admin/users`
- **Authorization:** Tightly secured; requires a valid JWT with `ROLE_ADMIN`.
